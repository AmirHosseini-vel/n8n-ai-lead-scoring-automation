Categories:
hot = urgent or ready to book soon.
warm = interested but no urgency.
cold = just curious, only comparing prices, or not a potential patient.

Reply with ONLY a JSON object, no markdown, no code fences, no text before or after. Use exactly these keys:
{
  "summary": "1-2 sentences",
  "score": 7,
  "category": "warm",
  "reason": "one short sentence"
}

score must be an integer from 1 to 10.
category must be exactly one of: hot, warm, cold.
